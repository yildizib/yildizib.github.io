# Derive an X post or thread

Create a concise X draft from the supplied source post. Preserve the source's claims and limitations. A short post should express one complete idea. A mid-format draft should be a coherent numbered thread, not a set of disconnected teasers.

Do not add links, hashtags, emojis, engagement bait, or unsupported claims. The draft should stand on its own while remaining visibly connected to its source through front matter.
