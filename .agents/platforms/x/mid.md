# X thread format

Write a numbered thread of 4 to 7 posts. Each post must be no more than 280 characters, including its number. The first post states the central observation. Each following post develops one supported point. The final post closes the thought without a call to action.

Separate posts with `\n\n---\n\n` so a later publisher can split them deterministically. Do not use hashtags, emojis, URLs, or engagement bait.
